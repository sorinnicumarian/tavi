To capture temporal dependencies, we have traced every interaction that the agent has with the AI2-THOR environment. The \texttt{TraceCollector}
class is responsible for collecting the trace information of the environment after each action. Every detail in the trace is transformed
into meaningful predicates used later for LTL checking. 

We store each task step as a JSONL file which conveys the task identifier, step identifier, timestamp, executed action, predicates,
predicates added or removed during this step, and the execution result. Since we update the JSONL file incrementally after each step, 
this allows us to conduct online verification as we can access the file after each step. 

The proposed framework does not retrieve all of the AI2-THOR possible metadata. Rather, it retrieves only a limited vocabulary of predicates
which are directly related to safety checking. The vocabulary consists of predicates like \texttt{visible}, \texttt{near}, 
\texttt{on}, \texttt{holding}, \texttt{open}, \texttt{toggled\_on}, \texttt{hot}, \texttt{cold}, \texttt{broken}, 
\texttt{pickupable}, \texttt{toggleable}, \texttt{openable}, \texttt{flammable}, \texttt{heat\_source}, \texttt{sharp}, 
\texttt{electrical}, and \texttt{chemical}. Furthermore, we also express actions in terms of predicates, storing them with the template
\texttt{exec\_\_ActionName\_\_Object}, as we utilize the object predicates of previous steps and the action predicate of the next step
to see if the action will be hazardous or not.

The reason why we chose a closed predicate vocabulary is because leaving the vocabulary open would often produce new rule predicates which
were not part of the original traces, leading to traces automatically complying to the rules and leaving potential hazards undetected. 
This problem was fixed by the \texttt{trace\_predicates.md} file, which inludes all the predicates that can appear in the traces. The file
is utilized as context to the LTL rule generator, ensuring that the predicates are consistent between traces and the rules.
