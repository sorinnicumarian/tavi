### How to run

## Plain english rule generation

python3 src/main_engligh_rule_generator.py

## LTL rule generation

python3 src/main_ltl_template_generation.py

# !Note

The ltl script needs to take the plain_english_rules.json generated by the previous script in order to work.

plain_english_rules.json needs to be moved outside its "run_*" folder and added to the outputs folder in order to be detected.
