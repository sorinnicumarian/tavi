# LTL Formula Repair Rules

## Purpose

This file defines post-processing repairs applied to LTL formulas generated by the LLM pipeline.
The LLM sometimes produces predicates that do not exist in the trace schema. This file lists those
known mistakes and their canonical replacements so repairs can be applied without touching code.

---

## Non-existent predicates

These predicates are commonly hallucinated by the LLM but have no implementation in the trace
processor. Formulas that still contain any of these after rewriting are marked not_expressible.

```
isBroken__
shattered__
cracked__
on_floor__
grounded__
water__
liquid__
wet__
food_preparation_context__
enclosed__
```

---

## Canonical rewrites

Each rewrite below is applied in order before the non-existent predicate check.

### filled_with_liquid 3-arg → 2-arg

The LLM sometimes generates `filled_with_liquid__{x}__water` (3-arg form). The correct form
is always `filled_with_liquid__{x}` — the liquid type is not a separate argument.

Pattern (regex): `filled_with_liquid__({var})__\w+`
Replacement: `filled_with_liquid__{var}`

### isBroken__{x} → broken__{x}

The predicate `isBroken__` is a common LLM hallucination. The correct trace predicate is `broken__`.

Pattern (regex): `isBroken__({var})`
Replacement: `broken__{var}`
